# Press Kit Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `presskit.html` page that gives press and creators Underroot's logo, key art, screenshots, trailer, fact sheet, and boilerplate — downloadable individually and as one ZIP — linked from the homepage footer.

**Architecture:** A single self-contained static HTML page in the same hand-authored style as the rest of the site (inline `<style>`, dark-clay palette, Georgia serif, `kicker`→`title` sections, homepage footer). A committed ZIP bundle plus a helper script that documents how it's rebuilt. One footer link added to `index.html`.

**Tech Stack:** Static HTML/CSS + vanilla JS (clipboard copy, async Formspree POST). Node's built-in `zlib`/`fs` for the ZIP helper (no new dependencies). Python `http.server` for local preview. Verified in-browser (the project has no page-level test harness; game-logic JS is the only thing under `node --test`).

**Design spec:** `docs/superpowers/specs/2026-07-25-presskit-design.md`

**Testing note:** This is a static content page with trivial JS, matching `story.html` / `music.html` / `stats.html`, none of which have unit tests. Verification is done in the browser preview (console clean, assets resolve, links download, copy works, form submits) rather than with `node --test`. Each task ends in a commit.

- [ ] **Step 3: Write `scripts/build-presskit-zip.mjs`** — a dependency-free Node script that assembles the ZIP. It uses `zlib.deflateRawSync` and writes ZIP records by hand so there is no new npm dependency.

```js
// Rebuilds assets/press/underroot-press-kit.zip from source assets.
// Run after any press asset changes:  node scripts/build-presskit-zip.mjs
// Zero dependencies — writes a standard ZIP using Node's built-in zlib.
import { readFileSync, writeFileSync } from 'node:fs';
import { deflateRawSync, crc32 } from 'node:zlib';

const ROOT = new URL('..', import.meta.url);
const p = (rel) => new URL(rel, ROOT);

// [source path relative to repo root, name inside the zip]
const ENTRIES = [
  ['assets/images/Underroot_title.png', 'Underroot_title.png'],
  ['assets/images/Underroot_website_background.png', 'key-art.png'],
  ['assets/images/shots/shot_world.jpg', 'screenshots/shot_world.jpg'],
  ['assets/images/shots/shot_dig.jpg', 'screenshots/shot_dig.jpg'],
  ['assets/images/shots/shot_dig2.jpg', 'screenshots/shot_dig2.jpg'],
  ['assets/images/shots/shot_village.jpg', 'screenshots/shot_village.jpg'],
  ['assets/images/shots/shot_craft.jpg', 'screenshots/shot_craft.jpg'],
  ['assets/images/shots/shot_rain.jpg', 'screenshots/shot_rain.jpg'],
  ['assets/video/underroot_trailer.mp4', 'underroot_trailer.mp4'],
  ['assets/press/fact-sheet.txt', 'fact-sheet.txt'],
  ['assets/press/boilerplate.txt', 'boilerplate.txt'],
];

const enc = new TextEncoder();
const u16 = (n) => { const b = Buffer.alloc(2); b.writeUInt16LE(n >>> 0); return b; };
const u32 = (n) => { const b = Buffer.alloc(4); b.writeUInt32LE(n >>> 0); return b; };

const locals = [];
const centrals = [];
let offset = 0;

for (const [src, name] of ENTRIES) {
  const data = readFileSync(p(src));
  const comp = deflateRawSync(data);
  const crc = crc32(data) >>> 0;
  const nameBuf = Buffer.from(enc.encode(name));

  const localHeader = Buffer.concat([
    u32(0x04034b50), u16(20), u16(0), u16(8),      // sig, ver, flags, method=deflate
    u16(0), u16(0x21),                              // mod time, mod date (fixed, not "now")
    u32(crc), u32(comp.length), u32(data.length),
    u16(nameBuf.length), u16(0), nameBuf,
  ]);
  locals.push(localHeader, comp);

  centrals.push(Buffer.concat([
    u32(0x02014b50), u16(20), u16(20), u16(0), u16(8),
    u16(0), u16(0x21),
    u32(crc), u32(comp.length), u32(data.length),
    u16(nameBuf.length), u16(0), u16(0), u16(0), u16(0), u32(0),
    u32(offset), nameBuf,
  ]));
  offset += localHeader.length + comp.length;
}

const centralBuf = Buffer.concat(centrals);
const localBuf = Buffer.concat(locals);
const eocd = Buffer.concat([
  u32(0x06054b50), u16(0), u16(0),
  u16(ENTRIES.length), u16(ENTRIES.length),
  u32(centralBuf.length), u32(localBuf.length), u16(0),
]);

writeFileSync(p('assets/press/underroot-press-kit.zip'), Buffer.concat([localBuf, centralBuf, eocd]));
console.log(`Wrote assets/press/underroot-press-kit.zip (${ENTRIES.length} entries)`);
```

- [ ] **Step 4: Generate the ZIP**

Run: `node scripts/build-presskit-zip.mjs`
Expected: `Wrote assets/press/underroot-press-kit.zip (11 entries)`

- [ ] **Step 5: Verify the ZIP is valid and has the expected contents**

Run: `node -e "const {execSync}=require('node:child_process');" ` is not portable; instead unzip-list with Node is complex. Verify with the system tool:

Run (PowerShell): `Expand-Archive -Path assets/press/underroot-press-kit.zip -DestinationPath $env:TEMP/pk_check -Force; Get-ChildItem -Recurse $env:TEMP/pk_check | Select-Object -ExpandProperty Name; Remove-Item -Recurse -Force $env:TEMP/pk_check`

- [ ] **Step 3: Add the copy-button script** just before `</body>`:

```html
  <script>
    document.querySelectorAll('.copy-btn').forEach((btn) => {
      btn.addEventListener('click', async () => {
        const el = document.getElementById('bp-' + btn.dataset.copy);
        const text = el.textContent.trim();
        try {
          await navigator.clipboard.writeText(text);
        } catch {
          const r = document.createRange(); r.selectNodeContents(el);
          const sel = getSelection(); sel.removeAllRanges(); sel.addRange(r);
        }
        const old = btn.textContent; btn.textContent = 'Copied'; btn.classList.add('done');
        setTimeout(() => { btn.textContent = old; btn.classList.remove('done'); }, 1600);
      });
    });
  </script>
```
